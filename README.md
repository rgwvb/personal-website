# 鍾SIR 個人網站

以 584 網站的 person.html 人物介紹頁為視覺參考：深藍漸層封面、左側個人照片、金色點綴，搭配白底履歷時間軸與證照卡片。

網站程式由 GitHub 管理，內容從 Google Sheets 讀取。不需服務帳號 JSON 或 API 金鑰。

內容後台：https://docs.google.com/spreadsheets/d/1SkYEZfk11xIRQTR6RdRk0q-ih3-wT3KdlSOQ8BrMvzc/edit

## 更新內容

- 個人資料：修改內容欄，更新名稱、簡介、工具、照片與聯絡方式。「個人照片」填入公開 HTTPS 圖片網址，會替換封面左側的「鍾」字識別；留空則保留識別圖。
- 證照：一列一張，分別填證照名稱、類別、級別與證書網址。目前收錄九張證照，含數位電子、電腦軟體應用與電腦硬體裝修三張乙級。
- 經歷與榮譽：一列一項紀錄；類型填「榮譽」會出現在獲獎區，其餘會顯示在經歷時間軸。「單位或階段」填「大學」或「高中」會分區呈現；高三、高中職組等高中標記也會歸入高中區，其他內容會保留在其他經歷。
- 作品：一列一件作品，填標題、摘要、內容、標籤、圖片與連結。
- 最新消息：一列一則近況。
- 顯示填 TRUE 才顯示，FALSE 可隱藏。排序數字由小到大。
- 保留第一列欄名與分頁名稱，可往下新增資料。
- 圖片與檔案先上傳 GitHub 或其他公開空間，再貼網址。試算表儲存文字和網址，不直接存放檔案。

## 原始碼

- index.html：人物介紹版面、履歷與證照區。
- profile.css：深藍人物介紹風格與響應式版面。
- profile.js：五個分頁的資料讀取、證照篩選、作品介紹與導覽。
- assets：概念插畫，非實際量測數據或產品截圖。

支援 GitHub Pages 專案子路徑。沒有留言或訊息送出功能。已通過 JavaScript 語法與本機預覽檢查，確認五個分頁成功讀取、九張證照的類別篩選，以及作品介紹視窗正常。
